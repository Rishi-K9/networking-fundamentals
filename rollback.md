# Deployment Rollback

## Objective
To document how to restore a previous working version of the Networking Fundamentals website.

## Rollback Procedure
1. Open the GitHub repository.
2. Navigate to the commit history.
3. Identify the previous working version.
4. Revert the commit that introduced the problem.
5. Wait for GitHub Pages to redeploy.
6. Open the website and verify that it works.

## Recovery Method
GitHub commit history provides a record of changes and supports reverting unwanted changes.

## Conclusion
The rollback procedure provides a recovery plan if a website update causes a problem. A rollback test should be performed and its actual result recorded before claiming successful recovery.
