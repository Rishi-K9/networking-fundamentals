# Network Topology

## Objective
To illustrate how common network devices connect and help secure a network.

## Proposed Topology

```text
          Internet
              |
           Router
              |
          Firewall
              |
            Switch
           /      \
       PC-1        PC-2
```

## Device Roles
- Router: Connects different networks.
- Firewall: Filters network traffic.
- Switch: Connects computers on a local network.
- PCs: Represent client devices.
