# Networking Fundamentals

## 1. Objective
To understand basic networking concepts required for cybersecurity.

## 2. IP Address
An IP address identifies a device's network interface.
Example: `192.168.1.10`

## 3. MAC Address
A MAC address identifies a network interface on a local network.
Example: `00:1A:2B:3C:4D:5E`

## 4. Ports
Ports direct network traffic to specific applications.
- HTTP: 80
- HTTPS: 443
- DNS: 53

## 5. Protocols
- TCP: Reliable data delivery.
- UDP: Connectionless communication.
- IP: Addressing and routing.
- HTTP/HTTPS: Web communication.
- DNS: Resolves domain names to IP addresses.

## 6. Network Devices
- Router: Connects different networks.
- Switch: Connects devices within a local network.
- Firewall: Filters network traffic.
- Access Point: Provides wireless connectivity.

## 7. Network Topology
`Internet → Router → Firewall → Switch → Computers`

This is a conceptual topology, not a verified simulation.

## 9. Cybersecurity Relevance
Networking knowledge helps analyze traffic, understand services, configure firewalls, and troubleshoot network issues.

## 10. Interview Questions

**Q1. What is an IP address?**

A logical address used to identify a network interface and route data.

**Q2. What is a MAC address?**

An address used to identify a network interface on a local network.

**Q3. What is a port?**

A logical number used to direct traffic to an application or service.
